# 52Note 用户指南待修改清单

更新日期：2026-08-28

## 目的

本文件记录 52Note 内置用户指南中尚未完成的品牌、服务、链接和功能说明改造，供 Web 端及自研 Go 后端方案确定后统一处理。

修改指南时必须继续保留仓库中的 `LICENSE`、第三方声明以及“52Note 基于 SiYuan 构建”的来源说明，不得将 SiYuan 官方提供的服务描述成 52Note 自有服务。

## 指南来源与加载方式

- 简体中文指南源目录：`app/guide/20210808180117-czj9bvb`
- 英文及其他语言指南：`app/guide/20210808180117-6v0mkxr`
- 繁体中文指南：`app/guide/20211226090932-5lcq56f`
- 日文指南：`app/guide/20240530133126-axarxgx`
- 指南随安装包发布，不是在用户首次点击时远程下载。
- 用户点击“用户指南”后，程序从安装目录的 `resources/guide` 将相应指南复制到工作区 `data/<指南 ID>`。
- 只修改用户工作区中的指南副本不能持久生效；重新挂载指南时可能被安装包内置版本覆盖。

## 待修改：必须等待自研 Go 后端确定的内容

以下内容不能只替换名称，必须等 52Note 自有服务上线后重写：

- 用户注册、登录、退出、找回密码和账号注销。
- 用户协议、隐私政策及其正式网页地址。
- 云端同步、云端存储、备份、流量和容量限制。
- 多设备同步策略、冲突处理、快照和历史版本恢复。
- 会员、订阅、价格、订单、授权和权益说明。
- 收集箱、云端图床和依赖官方账号的功能。
- 服务端部署、Web 端入口和 API 域名。
- 服务状态、数据中心和地域选择。
- 后端安全、数据加密、密钥管理和数据删除政策。
- 管理员、团队空间、共享权限和协作能力。

在上述服务完成前，应隐藏对应入口，或明确标记为“暂未开放”，不得继续链接到 SiYuan 官方账号或付费服务。

## 待修改：网站和外部链接

- 下载最新版：改为 52Note 官方发布页或自有更新接口。
- 更新公告：改为 52Note 自有发布公告。
- 用户社区、问题反馈和帮助中心：等待自有网页地址确定。
- “给开发者捐赠”：按钮目前保留但不执行跳转，后续补充自有页面。
- GitHub：指向 52Note 仓库；涉及上游源码和许可证时保留 SiYuan 上游链接。
- Chrome/浏览器剪藏扩展：在 52Note 自有扩展发布前，不应把 SiYuan 扩展描述为 52Note 官方扩展。
- Android、Windows、macOS 和 Web 下载入口：等待各平台正式发布地址确定。
- 应用商店、ICP备案、隐私政策和用户协议链接：上线前统一核验。

## 待修改：当前版本已经改变或隐藏的功能

指南必须与 52Note 实际行为保持一致：

- 官方账号登录与同步入口当前暂时隐藏。
- 52Note 不再按照 SiYuan 官方更新策略下载新版本。
- Windows 安装不再修改 `PATH`，也不再创建仅用于命令行调用的 `siyuan.exe` 硬链接。
- Windows 不再注册原有 SiYuan 协议唤醒登录流程。
- 关闭按钮的新默认行为为最小化到系统托盘。
- 关于页面、捐赠按钮和外部网页入口以 52Note 当前实现为准。
- 尚未正式提供的 Web、账号和云同步功能不得写成已经可用。
